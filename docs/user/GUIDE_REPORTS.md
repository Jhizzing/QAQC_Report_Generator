## Report Types

### Figures Only Report

**Purpose**: Quick summary with charts and tables

**Contents**:
- Selected charts (control charts, scatter plots, histograms)
- Summary tables
- Figure captions
- Basic statistics

**Best For**:
- Appendices to larger reports
- Presentations
- Quick summaries
- Internal documentation

**When to Use**:
- Need charts and tables only
- Don't need full report structure
- Quick reference documents
- Supplementary materials

### JORC Report

**Purpose**: Complete analysis report compliant with JORC Code 2012

**Contents**:
- Cover page (if enabled)
- Executive summary
- Methodology section
- Results and interpretation
- All figures and tables
- Competent person information
- Company metadata
- Recommendations

**Best For**:
- JORC-compliant reporting
- Formal documentation
- Regulatory submissions
- Final project reports

**When to Use**:
- Need complete analysis report
- JORC compliance required
- Formal documentation needed
- Regulatory submissions

- Final reports

- Printing

- Regulatory submissions

- Reports requiring editing

## Customization Options

### Report Metadata

**Competent Person**:
- Name of competent person
- Required for JORC reports
- Appears on cover page and in report

**Company Name**:
- Your company or organization
- Appears in report header/footer

**Laboratory**:
- Laboratory name that performed assays
- Important for documentation

**Drilling Company**:
- Company that performed drilling
- Relevant for field duplicates

**Sample Type**:
- Type of samples analyzed
- E.g., "Drill Core", "RC Chips", "Soil"

**Comments**:
- Additional notes or comments
- Appears in report methodology section

### Visual Options

**Color Scheme**:
- **Default**: Colorful charts and tables
- **Grayscale**: Black and white (for printing)

**Font Size**:
- **Small**: More content per page
- **Medium**: Balanced (recommended)
- **Large**: Easier reading

**Page Layout**:
- **Portrait**: Standard reports (recommended)
- **Landscape**: Wide charts/tables

**Logo**:
- Add company logo URL or path
- Logo appears on cover page and headers

### Content Options

**Figure Inclusion**:
- **Include Control Charts**: Yes/No
- **Include Scatter Plots**: Yes/No
- **Include Histograms**: Yes/No
- **Include Summary Tables**: Yes/No

**Figure Size**:
- **Small**: Compact figures
- **Medium**: Standard size (recommended)
- **Large**: High-detail figures

**Figure Title**:
- Custom title for figures section
- Default: "QAQC Figures"

**Report Title**:
- Custom report title
- Default: "QAQC Analysis Report"

### Advanced Options

**Cover Page**:
- Include cover page (JORC reports)
- Shows report title, company, date

**JORC Table**:
- Include JORC compliance table
- Shows QAQC statistics

**Executive Summary**:
- Include executive summary section
- Highlights key findings

**Methodology Section**:
- Include detailed methodology
- Documents analysis approach

## Template Editing

### Accessing Template Editor

**From Report Workflow**:
1. Click "Templates" or "Edit Template"
2. Template editor opens

**From Sidebar** (if available):
1. Click "Templates" in sidebar
2. Template editor opens

### Template Structure

**Sections**: Major report sections
- Executive Summary
- Methodology
- Results
- Interpretation
- Recommendations

**Blocks**: Content blocks within sections
- Text blocks
- Table blocks
- Figure blocks
- Image blocks

**Properties**: Styling and formatting
- Font settings
- Color schemes
- Layout options

### Customizing Templates

**Add Section**:
1. Click "Add Section"
2. Enter section name
3. Choose section type
4. Section added to template

**Add Block**:
1. Select section
2. Click "Add Block"
3. Choose block type
4. Configure content
5. Block added to section

**Reorder Elements**:
- Drag and drop sections/blocks
- Use up/down arrows
- Reorder to customize flow

**Edit Properties**:
1. Select element (section or block)
2. Properties panel opens
3. Edit formatting, styling
4. Changes apply immediately

**Delete Elements**:
1. Select element
2. Click delete button
3. Confirm deletion
4. Element removed

### Saving Templates

**Save Template**:
1. Click "Save Template"
2. Enter template name
3. Template saved
4. Available for future use

**Load Template**:
1. Click "Load Template"
2. Select template
3. Template loaded
4. Use for report generation

**Default Template**:
- Application includes default template
- Can be customized
- Serves as starting point

## Best Practices for Reports

### Report Planning

**Before Generating**:
1. **Review results**: Ensure results are correct
2. **Select figures**: Choose relevant charts/tables
3. **Prepare metadata**: Gather competent person, company info
4. **Choose format**: Select appropriate export format
5. **Configure options**: Set customization options

### Report Content

**Essential Elements**:
- Executive summary
- Methodology
- Results and interpretation
- Key figures and tables
- Recommendations

**Optional Elements**:
- Project background
- Geological context
- Laboratory information
- Detailed statistics
- Appendices

### Report Quality

**Accuracy**:
- Verify all data is correct
- Check calculations
- Review statistics
- Validate results

**Completeness**:
- Include all relevant information
- Document methodology
- Explain findings
- Provide recommendations

**Clarity**:
- Use clear language
- Explain technical terms
- Use appropriate figures
- Organize logically

**Professionalism**:
- Consistent formatting
- High-quality charts
- Proper citations
- Professional appearance

### Report Organization

**Structure**:
1. Cover page (if applicable)
2. Executive summary
3. Methodology
4. Results
5. Interpretation
6. Recommendations
7. Appendices (if applicable)

**Figures**:
- Place figures near relevant text
- Number figures sequentially
- Include captions
- Reference in text

**Tables**:
- Place tables near relevant text
- Number tables sequentially
- Include headers
- Reference in text

### File Management

**Naming Conventions**:
- Use descriptive names
- Include date: `ProjectName_QAQC_2025-01-15.pdf`
- Include version if applicable
- Use consistent format

**Organization**:
- Store reports in organized folders
- Keep original data files
- Maintain report versions
- Document changes

**Backup**:
- Keep backup copies
- Store in multiple locations
- Version control if possible
- Archive old reports

### Sharing Reports

**Before Sharing**:
1. Review report for accuracy
2. Check formatting
3. Verify all information included
4. Test file opens correctly

**Sharing Methods**:
- Email (PDF recommended)
- File sharing services
- Project management systems
- Direct file transfer

**Documentation**:
- Note report purpose
- Document any limitations
- Include data sources
- Note analysis date

## Troubleshooting Report Generation

### Report Generation Fails

**Possible Causes**:
- Browser permissions
- Disk space
- File size limits
- Configuration errors

**Solutions**:
1. Check browser allows downloads
2. Verify sufficient disk space
3. Try different format
4. Check report configuration
5. Reduce figure count

### Report File is Corrupted

**Possible Causes**:
- Generation interrupted
- Browser issues
- File system problems

**Solutions**:
1. Regenerate report
2. Try different browser
3. Check disk space
4. Try different format

### Report Missing Content

**Possible Causes**:
- Configuration issues
- Data filtering
- Template problems

**Solutions**:
1. Check report configuration
2. Verify data exists
3. Review template settings
4. Check figure inclusion options

### Report Too Large

**Possible Causes**:
- High-resolution figures
- Too many figures
- Large datasets

**Solutions**:
1. Reduce figure resolution
2. Include fewer figures
3. Split into multiple reports
4. Use Excel format (smaller)
