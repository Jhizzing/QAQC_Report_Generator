### Python Dependencies

To view licenses for Python dependencies:

```bash
pip show <package-name>
```

Or generate a license report:

```bash
pip-licenses --format=json > licenses.json
```

### React UI Dependencies

To view licenses for npm dependencies:

```bash
cd react_ui
npm list --depth=0
```

Or use a license checker:

```bash
npm install -g license-checker
license-checker --json > licenses.json
```
