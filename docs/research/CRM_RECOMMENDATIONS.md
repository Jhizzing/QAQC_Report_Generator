# CRM Recommendations for pXRF and Multi-Element Geochemistry

## Executive Summary

This document provides recommendations for Certified Reference Materials (CRMs) suitable for pXRF and multi-element geochemistry QAQC. The recommendations are organized by application (pXRF, multi-element ICP, gold analysis) and matrix type to help users select appropriate CRMs for their specific needs.

## 1. CRM Selection Criteria

### 1.1 Matrix Matching

**Principle**: CRMs should match the matrix composition of samples as closely as possible.

**Matrix Types:**
- **Silicate Rocks**: Granite, basalt, rhyolite, andesite
- **Sulfide Ores**: VMS, porphyry, massive sulfide
- **Oxide Ores**: Laterite, oxide gold, iron ore
- **Carbonates**: Limestone, dolomite
- **Soils/Sediments**: Regolith, stream sediments, soil horizons

### 1.2 Concentration Range Coverage

**Principle**: Select CRMs that bracket the concentration range of samples.

**Best Practice:**
- Low-grade CRM: Near detection limit or lower end of sample range
- Mid-grade CRM: Near median of sample range
- High-grade CRM: Near upper end of sample range

### 1.3 Element Coverage

**Principle**: CRMs should contain certified values for all elements of interest.

**Priority Elements for Geochemistry:**
- **Base Metals**: Cu, Pb, Zn, Ni, Co
- **Precious Metals**: Au, Ag, PGE
- **Pathfinders**: As, Sb, Bi, Te, Se
- **Major Elements**: Fe, S, Al, Ca, Mg, K, Na, Ti
- **Trace Elements**: Mo, W, U, Th, REE

## 6. CRM Usage Guidelines

### 6.1 Selection Workflow

1. **Identify Sample Matrix**: Determine primary matrix type
2. **Identify Elements of Interest**: List all elements to be analyzed
3. **Determine Concentration Ranges**: Estimate sample concentration ranges
4. **Select 2-3 CRMs**: Choose CRMs that:
   - Match matrix type
   - Cover concentration range (low, mid, high)
   - Include all elements of interest
5. **Verify Availability**: Ensure CRMs are available and current
6. **Check Certificates**: Review certified values and uncertainties

### 6.2 Insertion Rates

**Industry Standard:**
- Minimum 5% insertion rate for standards
- Distribute evenly throughout sample batch
- Include at least one CRM per 20 samples

**Best Practice:**
- Use 2-3 different CRMs per batch
- Rotate CRMs to cover different concentration ranges
- Document CRM insertion in QAQC records

### 6.3 Acceptance Criteria

**Standards Acceptance:**
- Within ±2SD of certified value (warning)
- Within ±3SD of certified value (failure threshold)
- Or within percentage tolerance (10-15% typical)

**Documentation:**
- Record all CRM analyses
- Calculate recovery percentages
- Track pass/fail rates
- Document any failures and corrective actions

## 9. Conclusion

Selecting appropriate CRMs is critical for effective QAQC in geochemical analysis. The recommendations in this document provide guidance for selecting CRMs based on application (pXRF, multi-element, gold), matrix type, and element coverage. Users should select 2-3 CRMs that match their sample matrix and cover their concentration ranges, ensuring all elements of interest are included in the CRM certificates.

The current CRM database provides good coverage for gold analysis and moderate coverage for multi-element analysis, but could be enhanced with additional USGS standards, more pXRF-optimized CRMs, and better coverage of different matrix types.
