# LogiQore Reporter Beta Website Handoff

This document defines the reporter-side contract for publishing beta downloads on `logiqore.io`.

## Release Assets Produced

On tag push (`v*`), `.github/workflows/release.yml` now produces:

1. Platform bundles
`logiqore-reporter-ubuntu-latest.zip`
`logiqore-reporter-macos-latest.zip`
`logiqore-reporter-windows-latest.zip`
2. Integrity files
`SHA256SUMS.txt`
`SHA256SUMS.txt.asc` (when signing secrets are configured)
3. Website manifest
`logiqore-reporter-beta-manifest.json`

All files are uploaded as GitHub release assets.

## Manifest Format

`logiqore-reporter-beta-manifest.json` includes:

1. `product`: fixed string (`LogiQore Reporter`)
2. `channel`: release channel (`beta`)
3. `version`: release tag (for example `v1.0.0-rc4`)
4. `generated_at`: UTC timestamp
5. `artifacts`: list of asset records

Each artifact record includes:

1. `name`
2. `size_bytes`
3. `sha256` (when available in `SHA256SUMS.txt`)
4. `download_url` (optional; only set when a base URL is provided)

## Recommended Website Route

Create a dedicated page on the website repo:

`/products/reporter` or `/beta/reporter`

Suggested page blocks:

1. Hero (LogiQore Reporter Beta)
2. Primary CTA (Launch Web Beta)
3. Download cards (Windows/macOS/Linux)
4. Integrity section (checksums + signature)
5. Feedback CTA

## Website Data Source

Prefer reading `logiqore-reporter-beta-manifest.json` from the latest GitHub release asset.

If `QAQC_Report_Generator` remains private, configure a public mirror repo for release assets.
The release workflow supports this via:

1. Repository variable: `PUBLIC_RELEASE_REPO` (for example `Jhizzing/logiqore-reporter-downloads`)
2. Repository secret: `PUBLIC_RELEASE_TOKEN`
   - Use a fine-grained PAT scoped only to the public mirror repository
   - Minimum permission: `Contents: Read and write`

When configured, the `Publish Public Download Mirror` job copies zipped binaries and integrity
metadata from the private source release to the public mirror release with the same tag.

Fallback:

1. Enumerate release assets by filename pattern
2. Parse `SHA256SUMS.txt` for integrity values

## Reporter-Side Naming Contract

Current executable basenames generated by PyInstaller:

1. `LogiQore-Reporter-GUI`
2. `LogiQore-Reporter-CLI`

Current installer naming:

1. Windows setup: `LogiQore-Reporter-Setup.exe`
2. macOS DMG: `LogiQore-Reporter-<version>.dmg`
3. Linux AppImage: `LogiQore-Reporter-<version>-x86_64.AppImage`
