## Choosing a License for Your Project

If you're building on this software:

**MIT License** (Recommended):
- Simple and permissive
- Allows commercial use
- Widely recognized
- Good for libraries and tools

**GPL v3**:
- Requires derivative works to be open source
- Good if you want to ensure code stays open
- Not compatible with proprietary software

**Apache 2.0**:
- Similar to MIT but includes patent grant
- Good for enterprise software
- More complex than MIT

**Proprietary**:
- All rights reserved
- No open source
- Requires custom license agreement
